# Qivlink

Fast, privacy-focused URL shortener, simple QR code generator, long-form Markdown pastebin, and 10MB file sharing service with an automated 7-day rolling data lifecycle.

## Features

- **Link Shortener**: Instant URL shortening with tracking/UTM sanitization.
- **Simple QR Code**: Fast, clean QR code generation with 1-click PNG download and clipboard copy.
- **Paste & Docs**: Paste or write notes and code of any length. Supports Markdown formatting, live preview, styled PDF export, and shareable short links.
- **File Sharing**: Upload files up to 10MB (PDFs, images, documents, audio, zip) with instant download links and QR codes.
- **Device Sharing**: Quick cross-device content transfer using device IDs and 6-digit drop codes.
- **History**: Unified index of active links, documents, and files with 7-day automated expiration countdowns.
- **Security**: Strict protocol whitelisting (`http:` and `https:`) and SSRF protection.

## Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
